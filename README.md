## Структура репозитория

Каждая лабораторная/практическая работа хранится в отдельной папке:

- `work-01` — Написание и компиляция консольного приложения в среде разработки MVS 2022
- `work-02` — Форматированный вывод и простые вычисления
- `work-03` — Ввод/вывод данных и простые вычисления
- `work-04` — Особенности использования данных различного типа
- `work-05` — Использование функций стандартной библиотеки языка Си
- `work-06` — Реализация разветвляющихся алгоритмов
- `work-07` — Многоальтернативная обработка

Внутри каждой работы находится файл `readme.txt` с названием темы, описанием выполненных заданий, информацией о компиляции и запуске программы.

Исходный код программ хранится в файлах с расширением `.c`.

В домашних заданиях работ 4 и 5 ввод данных и вывод результата выполняются в `main`, а основной расчёт — в отдельной функции, которая принимает значения через параметры и возвращает результат в `main`. Объявление функции находится перед `main`, реализация — после него. Такой же стиль используется при оформлении следующих лабораторных работ.
