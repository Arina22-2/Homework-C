Название: Особенности использования данных различного типа

Автор: Федянина Арина

Описание: Работа содержит три основных задания и индивидуальное домашнее задание. Реализованы ввод и вывод данных различных типов, выделение целой и дробной частей числа, вывод кода символа, вычисление обратного значения, преобразование типов, обработка цифр трёхзначного числа и проверка кратности трём заданных параметров.

Язык программирования: C

Компиляция: Проект создан в Visual Studio Code. Для сборки используется компилятор GCC.

Запуск: Для запуска программы используется кнопка Run C/C++ File в Visual Studio Code.
