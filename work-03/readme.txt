Название: Ввод/вывод данных

Автор: Федянина Арина

Описание: Работа содержит три основных задания и индивидуальное домашнее задание. Реализованы ввод данных с клавиатуры с помощью scanf(), выполнение арифметических операций, пересчет английских и испанских дюймов в сантиметры, форматированный вывод таблицы и расчет температуры по Фаренгейту и Кельвину по заданному значению в градусах Цельсия.

Язык программирования: C

Компиляция: Проект создан в Visual Studio Code. Для сборки используется компилятор GCC.

Запуск: Для запуска программы используется кнопка Run C/C++ File в Visual Studio Code.
