Название: Форматированный вывод и простые вычисления

Автор: Федянина Арина

Описание: Работа содержит несколько отдельных программ на языке C:

1. task1_formatting.c — использование printf(), управляющих символов, ширины поля и точности вывода.
2. task2_time.c — вывод и вычисление числовых значений времени.
3. task3_variant14.c — деление числа n на L с форматированным выводом результата, вариант 14.
4. task4_water_speed.c — определение минимальной скорости движения человека по воде.

Язык программирования: C

Компиляция: Проект создан в Visual Studio Code. Для сборки используется компилятор GCC.

Запуск: Для запуска программы используется кнопка Run C/C++ File в Visual Studio Code.
