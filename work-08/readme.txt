Название: Цикл с параметрами

Автор: Федянина Арина

Вариант: задание 2 — вариант 1, задание 3 — вариант 13. Остальные задания общие.

Описание: Реализованы печать заданного количества символов, сумма целых чисел между двумя границами, вывод степеней двойки и перевод результата в K = 1024, табулирование функции и вычисление суммы ряда. Используется цикл for. Функции объявлены перед main и реализованы после main. Ввод и вывод выполняются в main.

Файлы:
task0_symbols.c — обычная строка, строка с плюсами, две половины разными символами и восклицательный знак после каждого символа. Для нечётной длины вторая половина на один символ длиннее.
task1_sum.c — сумма от m до n включительно. Допускается ввод границ в любом порядке. После расчёта выводится число повторений цикла.
task1a_powers.c — вывод степеней 2 от 0 до n, затем степеней, не превышающих введённое m. Числа выровнены по правому краю. Для второй части значения в K выводятся с одним знаком после точки. Степень n ограничена диапазоном 0–30, чтобы результат помещался в int.
task2_table_variant1.c — таблица f(x) = x^2 + sin(5*x) на отрезке [0.1; 2.1]. Углы в радианах. Шаг вводится пользователем. Правая граница выводится, если попадает на сетку с выбранным шагом. Для удобства вывода допускается не более 10000 строк.
task3_series_variant13.c — сумма n слагаемых: 1/3^2 + 1/5^2 + ... + 1/(2*n+1)^2.

Контрольные примеры:
Задание 0: n = 5, символы * и #. Две половины: **###. С плюсами: +*****+.
Задание 1: m = 1, n = 5 — сумма 15, цикл выполнен 5 раз. При m = 5, n = 1 результат тот же.
Задание 1А: n = 11 — 2^11 = 2048 = 2 K. При m = 1331 выводятся степени до 1024, само m равно 1.3 K после округления.
Задание 2: шаг 1 — строки для x = 0.1, 1.1, 2.1; f(x) = 0.489426, 0.504460, 3.530304.
Задание 3: n = 3 — сумма 0.1715192744.

Схема повторения для задания 3:
Начало -> Ввод n -> sum = 0
-> [Повторение: i от 0 до n-1]
   denominator = 2*i + 3
   sum = sum + 1/(denominator*denominator)
-> Конец повторения -> Возврат суммы -> Вывод -> Конец.

Язык программирования: C

Компиляция: Каждый файл .c является отдельной программой и компилируется отдельно. Можно использовать GCC. Для task2_table_variant1.c при необходимости добавить параметр -lm.

Запуск: Открыть нужный файл в Visual Studio Code и нажать Run C/C++ File. Вещественные числа вводить с точкой. Символы вводить однобайтовые, например *, #, +. Для русского текста в терминале нужна кодировка UTF-8.
