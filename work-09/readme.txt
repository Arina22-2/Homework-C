Название: Вложенные циклы

Автор: Федянина Арина

Вариант: задание 1 — вариант 13, задание 2 — вариант 1, задание 3 — вариант 13.

Описание: Реализованы таблица Пифагора, её левый нижний треугольник, числовой узор, подсчёт количества цифр 3 и рисование заполненной прямоугольной трапеции. Применяются вложенные циклы и do-while. Функции объявлены перед main и реализованы после main. Ввод и вывод выполняются в main, функции вычисляют значения для вывода.

Файлы:
task1_pythagoras.c — полная таблица умножения 10 на 10 с заголовками и левый нижний треугольник без заголовков. Внешний цикл перебирает строки, внутренний — столбцы.
task1_pattern_variant13.c — числовой узор варианта 13. В первой строке пять чисел от 20 до 24. В следующих строках количество чисел и начальное значение уменьшаются на 1.
task2_count_threes_variant1.c — количество цифр 3 в целом числе типа long long. Обрабатываются ноль и отрицательные числа. После каждого расчёта можно повторить ввод: y — продолжить, n — закончить. Повторение организовано циклом do-while.
task3_trapezoid_variant13.c — заполненная прямоугольная трапеция. Пользователь задаёт высоту h в строках, верхнее основание b в символах, нижний острый угол в градусах и символ заполнения. Левая сторона вертикальная, правая расширяется книзу. Ширина строки i: b + округление(i / tan(угол)). На сетке из h строк между верхней и нижней строкой h-1 промежутков. Размеры округляются до целого числа символов. Допускаются h от 2 до 50, b от 1 до 100, угол от 0 до 90 градусов без границ; максимальная ширина — 200 символов.

Контрольный пример числового узора:
20 21 22 23 24
19 20 21 22
18 19 20
17 18
16

Контрольные примеры подсчёта цифр:
30333 — 4; -313 — 2; 0 — 0; 123456789 — 1.
После ввода 303, ответа y, ввода 0 и ответа n программа выводит 2 и 0, затем завершается.

Трапеция при h = 4, b = 3, угле 45 градусов и символе *:
***
****
*****
******

Язык программирования: C

Компиляция: Каждый файл .c является отдельной программой и компилируется отдельно. Можно использовать GCC. Для task3_trapezoid_variant13.c при необходимости добавить параметр -lm.

Запуск: Открыть нужный файл в Visual Studio Code и нажать Run C/C++ File. Вещественные числа вводить с точкой. Символ заполнения — однобайтовый, например *. Для русского текста в терминале нужна кодировка UTF-8.
