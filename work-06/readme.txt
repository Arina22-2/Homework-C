Название: Реализация разветвляющихся алгоритмов

Автор: Федянина Арина

Вариант: 13

Описание: Работа содержит три задания и домашнее задание на сложные условия. Реализованы проверка високосного года, вычисление кусочно заданной функции, выбор чисел из интервала (-1, 1) и проверка принадлежности точки заданной области. Ввод и вывод выполняются в main, расчёты и проверки условий — в отдельных функциях. Перед main записаны объявления функций, после main — их реализации.

Язык программирования: C

Компиляция: Каждый файл .c — отдельная программа со своей функцией main. Собирать и запускать файлы нужно по одному. Для сборки можно использовать GCC.

Запуск: Открыть нужный файл в Visual Studio Code и нажать Run C/C++ File. Вещественные числа вводить с точкой, например -0.5.

Условия заданий, алгоритмы и контрольные примеры приведены в README.md.
