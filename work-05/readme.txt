Название: Использование функций стандартной библиотеки языка Си

Автор: Федянина Арина

Описание: Работа содержит три основных задания и индивидуальное домашнее задание. Реализованы вычисление синуса угла, заданного в градусах, расчёт выражений с использованием математических функций стандартной библиотеки и проверка логических условий для целых частей полученных значений.

Язык программирования: C

Компиляция: Проект создан в Visual Studio Code. Для сборки используется компилятор GCC.

Запуск: Для запуска программы используется кнопка Run C/C++ File в Visual Studio Code.
