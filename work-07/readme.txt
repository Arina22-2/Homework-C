Название: Многоальтернативная обработка

Автор: Федянина Арина

Вариант: 13

Описание: Реализованы исходный пример распознавания символов a и b, определение латинской буквы или цифры, калькулятор и вывод стоимости покупки в рублях и копейках с правильным склонением слова «копейка». Выбор выполняется оператором switch. Расчётные функции объявлены перед main и реализованы после main. Ввод и вывод выполняются в main.

Язык программирования: C

Компиляция: Каждый файл .c является отдельной программой и компилируется отдельно. Можно использовать GCC.

Запуск: Открыть нужный файл в Visual Studio Code и нажать Run C/C++ File. В калькуляторе вводить выражение без пробелов, вещественные числа — с точкой, например 4*2.5.

Условия, алгоритмы, блок-схемы и контрольные примеры приведены в README.md.
