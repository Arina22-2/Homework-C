Название: Конструирование функций

Автор: Федянина Арина

Вариант: 1

Описание: Работа посвящена созданию собственных функций, передаче параметров и возврату результата. Объявления функций расположены перед main, реализации — после main. В main организованы ввод данных, выбор пунктов меню и вывод результатов вычислений. Определение и рисунок квадрата выводятся отдельными функциями void по образцу задания.

Файлы:
task1_functions.c — вычисление двух заданных функций и действий над ними. fa(x) = x^2 - 3*x + 9 при x <= 3, иначе 1/(x^3 + 3). fb(x) = x * exp(sin(x^2)). Через меню можно выбрать значение одной функции, произведение, разность квадратов fa^2 - fb^2, удвоенную сумму или все результаты. Пункт 0 завершает программу.
task2_sine.c — общий пример задания 2. Сравниваются sin(x) из math.h, сумма первых N слагаемых ряда и сумма ряда с заданной точностью eps. Следующий член вычисляется из предыдущего, без отдельного вычисления факториала. Перед суммированием угол приводится к промежутку [-pi; pi] с учётом периодичности синуса.
task2_exp_variant1.c — индивидуальный вариант 1 задания 2. Сравниваются exp(-x), сумма первых N слагаемых ряда 1 - x + x^2/2! - x^3/3! + ... и сумма с заданной точностью eps. N включает начальную единицу. В таблице выводятся значения и абсолютные отклонения от библиотечной функции.
task3_square_variant1.c — меню для квадрата: вычисление площади, вывод определения, рисование заполненного квадрата символом * и сравнение площадей двух квадратов. Каждая операция реализована своей функцией. Для рисунка допускается сторона до 50 символов. Для площади и сравнения сторона может быть больше 50.

Контрольные примеры:
Задание 1: x = 0, пункт 6. fa = 9, fb = 0, произведение = 0, разность квадратов = 81, удвоенная сумма = 18.
Задание 1: x = 3 — fa = 9. При x = 4 значение fa = 1/67 = 0.0149253731.
Синус: x = 1, N = 5, eps = 0.00000001. Сумма N членов равна 0.8414710097, библиотечное значение — 0.8414709848.
Вариант 1: x = 1, N = 5, eps = 0.00000001. Сумма N членов равна 0.375, exp(-1) = 0.3678794412.
Вариант 1: x = 0 — результат 1; x = -1 — exp(1) = 2.7182818285.
Квадрат со стороной 3: площадь 9. При сравнении со стороной 2 разность площадей равна 5.

Для рядов вводятся x, N от 1 до 1000 и точность 0 < eps < 1. Углы задаются в радианах. Сумма с фиксированным N может отличаться от библиотечного значения, если слагаемых недостаточно. При больших значениях x в ряде для exp(-x) возможно накопление ошибок округления или переполнение. Если фактическое отклонение превышает eps, программа сообщает, что заданная точность не достигнута.

Язык программирования: C

Компиляция: Каждый файл .c является отдельной программой и компилируется отдельно. Можно использовать GCC. Для task1_functions.c, task2_sine.c и task2_exp_variant1.c при необходимости добавить параметр -lm.

Запуск: Открыть нужный файл в Visual Studio Code и нажать Run C/C++ File. Вещественные числа вводить с точкой. Для русского текста в терминале нужна кодировка UTF-8.
